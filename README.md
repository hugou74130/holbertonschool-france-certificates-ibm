## 🧐 About <a name = "about"></a>

This repository serves as a digital archive of IBM SkillsBuild certifications obtained through the Holberton School France program. Each certificate represents a completed module in cutting-edge technology tracks provided by IBM.

## 🏁 Getting Started <a name = "getting_started"></a>

These instructions will help you view the certificates locally.

### Prerequisites

- A PDF reader (any modern browser will suffice)
- Git

### Viewing

Clone the repository and open any `.pdf` file:

```bash
git clone https://github.com/hugou74130/holbertonschool-france-certificates-ibm.git
cd holbertonschool-france-certificates-ibm
```
